This repo contains a single-session laboratory activity that introduces students to statistical analysis in [R](https://www.r-project.org/) using publicly available water quality data from the Elwha River estuary (Washington, USA). The data come from the USGS data release [Water quality in the Elwha River estuary, Washington, from 2006 to 2014 (doi:10.5066/F75B00N4)](https://www.usgs.gov/data/ecological-parameters-elwha-river-estuary-and-during-dam-removal-ver-20-august-2020). 

Repo metadata:
- `R_lab_notebook.html`: This functions as a manual for the lab activity. It is knitted from `R_lab_notebook.Rmd`.
- `R_lab_notebook.Rmd`: Students can work directly within this Markdown document by editing and running the specified chunks as needed.
